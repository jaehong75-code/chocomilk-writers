개인정보처리방침

시행일 2026-11-10 · 참교육 초코우유 작가실

1. 누가 쓰나

이 도구는 채널 「참교육 초코우유」 운영자 한 사람만 쓰는 내부 도구입니다. 다른 사용자의 Google 계정에 로그인을 요청하지 않습니다.

2. 어떤 데이터에 접근하나

운영자가 Google OAuth로 허락한 범위 안에서 운영자 본인 채널의 데이터만 씁니다: YouTube Data API(youtube.force-ssl — 자기 채널 영상 목록·통계·댓글 읽기, 운영자가 고른 영상의 업로드·수정, 운영자가 쓴 댓글 게시)와 YouTube Analytics API(yt-analytics.readonly — 자기 채널 분석 보고서 읽기).

3. 어떻게 저장하나

가져온 통계는 운영자 개인 컴퓨터의 표(CSV)에만 저장합니다. 시청자 댓글은 내용과 날짜만 저장하고 작성자 이름·채널 정보는 저장하지 않습니다. 인증 토큰은 운영자 컴퓨터의 사용자 폴더에만 있고 다른 곳으로 보내지 않습니다.

4. 공유·판매

어떤 데이터도 제3자에게 판매·공유·이전하지 않으며, 광고에 쓰지 않습니다. 운영자의 채널 기획(어떤 이야기를 언제 만들지) 외의 용도로 쓰지 않습니다.

5. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

6. 삭제·철회

운영자는 언제든 Google 계정의 서드 파티 액세스에서 이 도구의 권한을 철회할 수 있고, 그러면 토큰은 더 이상 쓰이지 않습니다. 컴퓨터에 저장된 표는 운영자가 지울 수 있습니다. 삭제 요청: chocouyunl@gmail.com
